# Experiment plan (project charter)

What experiments exist in this repository, where each stage of them lives, and
how to rerun them.

## Layout contract

```
src/            living code (see src/README.md): design/, examples/, utils/
data/raw/       source datasets as received (never edited)
data/external/  third-party format inputs (JMP files, byte-identical to raw/)
data/interim/   generated artifacts — reproducible, may be regenerated
experiments/    one directory per experiment: scripts/ + results/
reports/        figures/ (and tables/) shared across experiments
notebooks/      exploratory notebooks (not authoritative)
docs/           this charter
reference/      study material: books, slides, extracted text, summaries
archive/        retired course code and deliverables — not built, not tested
tooling/        doc-extraction scripts that maintain reference/
```

Rule of thumb: **raw is sacred, interim is disposable, results are committed.**

## Design-plan inventory

| Plan | Design type | Generated by | Seed |
|------|-------------|--------------|------|
| `data/interim/Plan.csv` | Completely randomised, 12 loaves × 3 bake times | `src/design/generate_plans.R` (`make_bread_plan`) | 7638 |
| `data/interim/CopterDes.csv` | Randomised 3 × 3 factorial, 18 runs | `src/design/generate_plans.R` (`make_copter_design`) | 2591 |
| `data/interim/RCBPlan.csv` | Randomised complete block, 4 flower types × 4 blocks | `src/design/generate_plans.R` (`make_rcb_plan`) | 101 (book example unseeded) |

Regenerate all three with:

```sh
Rscript src/design/generate_plans.R
```

These plans are **sources**, not inputs to be read back and edited. The chapter
examples call the same `make_*` functions, so no script re-derives a plan by
hand and the examples cannot silently diverge from the unit.

## Experiment inventory

| Experiment | Question / brief | Design | Analysis | Result |
|------------|------------------|--------|----------|--------|
| Semester project: multi-response desirability optimisation | `archive/course/deliverables/STAT 5309 SP19 SEMESTER PROJECT_1.docx` | two-level factorials, a rotatable CCD, and response-surface / desirability methods (methods drawn from `src/examples/Chapter3.R` and `Chapter10.R`) | `experiments/semester-project/scripts/desirability.R` (optimisation) and `semester_project_twilson.Rmd` (report) | `experiments/semester-project/results/semester_project_twilson.pdf`, figures regenerated into `reports/figures/` |

The four problems in the brief are analysed from the datasets in `data/raw/`:

| Problem | Dataset | Design |
|---------|---------|--------|
| 1 — epitaxial layer thickness | `data/raw/01epitaxial_data.csv` | 2² factorial, 4 replicates |
| 2 — alloy cracking | `data/raw/02cracking_data.csv` | 2⁴ factorial, 2 replicates |
| 3 — conversion vs activity | `data/raw/03conversion_data.csv` | rotatable CCD, 3 factors |
| 4 — filtration time | `data/raw/04fitration_data.csv` | 2² response surface with axial runs |

The course labs and exams in `archive/course/` are teaching artifacts kept for
provenance; they are not experiments under this charter.
